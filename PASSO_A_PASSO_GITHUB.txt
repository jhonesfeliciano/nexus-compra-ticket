PASSO A PASSO — NEXUS COMPRA & TICKET
======================================

REPOSITÓRIO CONFIGURADO NOS LOADERS:
jhonesfeliciano/nexus-compra-ticket

1) No GitHub, crie um NOVO repositório público chamado:
   nexus-compra-ticket

2) Extraia este ZIP.

3) Envie o conteúdo desta pasta para a RAIZ do repositório. A raiz precisa mostrar:
   manifest.json
   loaders/
   releases/
   README.md

4) Confira a versão publicada:
   releases/1.3.0/teresina/nexus-compra-ticket-teresina.js
   releases/1.3.0/palmas/nexus-compra-ticket-palmas.js

5) Instale no Tampermonkey somente o loader correspondente:
   TERESINA -> loaders/NEXUS_COMPRA_TICKET_LOADER_TERESINA.user.js
   PALMAS   -> loaders/NEXUS_COMPRA_TICKET_LOADER_PALMAS.user.js
   MATRIZ   -> loaders/NEXUS_COMPRA_TICKET_LOADER_MATRIZ.user.js

6) IMPORTANTE:
   A janela deste script não aparece em todas as páginas do sistema.
   O loader espera a grade de Cobranças com Semana + Região + Total + Ticket Médio.
   Somente quando essa grade existir a interface Compra & Ticket será aberta.

7) No Nexus HTML, use “Solicitar Compra e Ticket”. Depois abra a página do relatório de Cobranças.
   O painel do Tampermonkey permite:
   1. Capturar tabela
   2. Ver solicitação
   3. Atender solicitação e enviar

8) MATRIZ:
   Se a solicitação tiver ecosystemKey=teresina ou ecosystemKey=palmas, o Loader MATRIZ escolhe o canal automaticamente.
   Se não houver solicitação pendente ou houver ambiguidade, ele mostra TERESINA/PALMAS para escolha manual.

9) ATUALIZAÇÃO FUTURA:
   - crie releases/NOVA_VERSAO/...
   - NÃO apague a versão antiga
   - atualize manifest.json somente quando quiser colocar a nova versão em uso

10) ROLLBACK:
   Para voltar a uma versão antiga, basta apontar manifest.json para o path antigo novamente.
